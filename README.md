# Car_Price_Prediction
Car Price Prediction  A beginner-friendly AI/ML project that predicts the selling price of a used car based on factors such as brand, year, kilometers driven, fuel type, transmission, number of owners, and engine capacity.  The project uses Python, Pandas, Scikit-learn, and Random Forest Regression. 

# 🚗 Car Price Prediction

**Building AI course project**

## Summary

Car Price Prediction is an AI/ML project that predicts the selling price of a used car using features such as brand, year, kilometers driven, fuel type, transmission, number of owners, and engine capacity.

## Project Objective

The main objective of this project is to build a machine learning model that can estimate the expected selling price of a used car based on its features.

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Random Forest Regression
- Streamlit
- Google Colab

## Machine Learning Model

This project uses **Random Forest Regression** to predict car prices.

### Input Features

- Brand
- Manufacturing Year
- Kilometers Driven
- Fuel Type
- Transmission
- Number of Previous Owners
- Engine Capacity

### Output

The system provides an **estimated selling price of the car**.
